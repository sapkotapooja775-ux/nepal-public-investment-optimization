# Optimal Public Investment Allocation in Nepal

## Overview

This project develops a Mixed-Integer Linear Programming (MILP) framework for optimising public investment allocation across Nepal's seven provinces.

The model considers economic productivity, regional development disparities, poverty, infrastructure gaps, and investment requirements to identify efficient provincial and sectoral investment allocations.

## Research Objectives

- Maximise expected economic benefits from public investment.
- Incorporate regional development requirements.
- Respect government budget and sectoral investment constraints.
- Identify optimal provincial investment allocations.
- Evaluate alternative budget and policy scenarios.

## Methodology

The project uses Python, Pyomo, and the HiGHS optimisation solver to formulate and solve a public investment allocation problem.

## Study Area

Nepal's seven provinces:

- Koshi
- Madhesh
- Bagmati
- Gandaki
- Lumbini
- Karnali
- Sudurpashchim

## Technologies

Python | Pyomo | HiGHS | Pandas | NumPy | Matplotlib
